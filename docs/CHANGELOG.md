# 변경 이력

날짜는 작업한 날이고, 괄호 안은 `develop` 병합 커밋입니다. 기능별 분석 근거(오프셋, 함수, 실측값)는 [`analysis/findings.md`](../analysis/findings.md)에 있습니다.

## 2026-10-02 — 게임 안 창 2단계
### 추가
- **오버레이에 자원·군사·용병·인구 탭**을 더했습니다. 이제 패널의 탭이 모두 게임 안 창에 있습니다. 새 탭의 화면과 값은 게임에서 확인했고, 마우스로 하는 조작은 사용자 확인 전입니다. 패널은 오버레이가 뜨지 않을 때 쓰는 비상용으로 남깁니다.
- **한글 이름 입력**: 용병단 이름 칸에 커서가 있는 동안 한글 입력기를 켭니다. 복사·붙여넣기도 넣었습니다. 둘 다 게임에서 실제 입력으로 확인하기 전입니다.
- 안내("Insert: MLToybox")를 맵에 들어갈 때도 띄웁니다.
### 수정
- 버튼이나 키를 누른 채 창을 닫으면 다시 열 때 창이 마우스에 붙어 끌릴 수 있던 문제(단위 테스트로 확인. 실제 마우스로는 확인 전).
- 읽을 수 없는 `control.json`으로 시작했을 때 첫 변경이 파일을 기본값으로 덮던 문제. 이제 `control.json.bak`으로 사본을 남깁니다.
- 그 밖에 계획 A의 최종 리뷰에서 미룬 항목: 화면 출력용 큐 고르기, 꺼진 뒤의 큐 기록, 시험용 Present 호출, 작업 스레드 보호.

## 2026-10-01 — 게임 안 창 1단계
### 추가
- **게임 안 창(오버레이)**: Insert로 게임 화면 안에 MLToybox 창을 엽니다. 영주, 건설, 업그레이드, 상태 탭이 있고 값을 바꾸면 즉시 저장됩니다("적용" 버튼 없음). 자원·군사·용병·인구 탭은 다음 단계에서 옮기며, 그때까지는 패널을 씁니다.
- 새 DLL `native/mltoybox_overlay.dll`(DX12 화면 출력 후킹 + Dear ImGui). 그리기에 실패하면 스스로 꺼지고 게임과 다른 기능은 계속 동작합니다. `config.lua`의 `overlay = false`로 끕니다.
- 상태에 `overlay`(올렸는지, 상태, 이유)가 추가됐습니다. 오버레이 설정은 `bridge/overlay.json`에 저장됩니다.
- 개발 도구: `tools/capture-game.ps1`(게임 창 캡처, 키 메시지), `tools/lab/resize.lua`.

## 2026-10-01 — 용병 깃발
### 추가
- **수행원 꾸미기**([군사] 탭): 병력 생성·커스텀 용병 고용으로 만든 친위대 분대에 게임의 수행원 꾸미기 화면을 엽니다. 모드가 그 분대를 잠깐 영지의 수행원 분대로 두고 화면을 열며, 닫으면 되돌립니다. 새 명령 `customizeRetinue`, 상태 `retinue`.
- **커스텀 용병단 깃발**: [용병] 탭에서 순정 용병단 11개의 깃발 가운데 하나를 고를 수 있습니다. 색과 문장도 그 용병단의 것을 씁니다. 고르지 않으면 이전처럼 카드가 들어간 칸의 깃발을 물려받습니다.
### 수정
- 용병 탭의 용병단 표가 창 너비를 따라갑니다. 기본 창 너비에서 "도착 영지" 열이 잘리고 가로 스크롤이 생기던 문제.

## 2026-09-30 — 용병
### 추가
- **용병 탭**: 고용 창의 빈 칸을 순정 용병단으로 자동 보충합니다. 패널에서 등록한 커스텀 용병단(이름, 분대 구성, 고용비, 도착 영지)이 고용 창에 상시 뜨고, 고용하면 다시 채워집니다. 순정 용병단이 모두 고용 중이어도 커스텀은 뜹니다.
- **플레이어 환급**: 내가 고용한 용병단의 고용비를 국고에 돌려주고 유지비를 0으로 만듭니다. AI가 고용한 용병단은 건드리지 않습니다.
- **AI 잠금**: 커스텀 용병단은 고용 창이 닫혀 있는 동안 AI가 살 수 없는 가격으로 둡니다.
- 개발 도구: `tools/lab-load.ps1`(세이브 자동 로드), `tools/lab/`(용병 상태·고용 스크립트), `lab.ps1 -Vars`.
### 변경
- **군사 탭 "용병 비용·모집비 0"이 "민병대 모집비 0"이 됐습니다.** 예전에는 용병 표의 고용비를 0으로 만들어 AI 영주도 공짜로 고용했습니다. 용병을 무료로 쓰려면 [용병] 탭의 환급을 켜세요.

## 2026-09-30 — 릴리스 2
### 수정
- 성벽 배치 중 크래시(reading 0x738): 배치 제한 무시가 도로/성벽 배치 함수와 같은 배치 불가 플래그(+0x60C)를 지워서, 어느 영지에도 속하지 않는 지점에서 null 영지를 읽었다. 이제 도로 모드에서는 플래그를 건드리지 않는다(사용자 재현: 기능을 끄면 안 튕기고 켜면 튕김).

## 2026-09-30 — 릴리스 `main` (a7cc405)
### 추가
- **병력 생성 위치 선택**: [군사] 탭 "위치"에서 고른 영지의 영주 저택 옆에 생성하고, 재구성도 같은 위치에 합니다. 이전에는 항상 첫 번째 영지에 생성됐습니다. 모드는 내 영지 목록(`playerRegions`)을 보고합니다.
- **지역당 건물 개수 제한 해제**(건설): `buildingStats.maxInRegion`이 1인 9개 행(수비용 탑 등 영주 저택 모듈, 세금 징수소, 장작·식량 수레)을 0으로 만듭니다. 수비용 탑 2개 배치로 확인했습니다.
### 수정
- **패널이 상태를 통째로 버리던 문제**: 모드가 빈 표를 `[]`로 보내면(예: `spawn.byUnit`) 패널이 상태 전체를 읽지 못했습니다. 그래서 "연결 안 됨", "현재: -", 빈 영지 목록이 나왔습니다.
- **인구**: 모드가 명령으로 들인 가족에도 배율이 붙어, 1가족을 들이면 3가족이 됐습니다. 이제 영지별로 따로 세어 제외합니다.
- **인구**: 모든 영지 합계에 미배치 가족 수가 빠져 있었습니다.

## 2026-09-29
### 추가
- **영주 탭**: 국고, 영향력, 왕의 총애를 영지별 자원과 분리해 목표를 유지합니다. 항목마다 따로 켤 수 있고, **지금 설정** 버튼으로 한 번에 정확히 맞춥니다(내리기 포함). 예전 설정의 `targets.Treasury/Influence`는 자동으로 옮겨집니다.
- **영지별 자원**: 영지마다 재고를 보여 주고 목표를 따로 지정합니다(`regionTargets`, 빈칸 = 공통).
- **영지별 인구**: 배율은 그 영지의 자연 이민만큼 그 영지에 적용됩니다. 목표는 "영지마다 최소 N가족"이며 영지별로 지정할 수 있습니다. 가족 추가는 영지를 지정하거나, 빈 자리가 많은 영지부터 채웁니다. 영지별 통계도 보여 줍니다.
- **생성 분대 재구성**: 해제로 0/N 빈 카드가 된 생성 분대를 같은 병종으로 다시 만들고, 빈 카드는 `removeSquad`로 정리합니다.
### 수정
- **크래시 방어 2차**(`militia_guard_2`): AI 틱의 형제 함수 `0x144B923D0`도 같은 null `Home` 읽기를 합니다.
- **인구**: 추가한 가족이 자기 집 일꾼으로 배치돼 들어오던 문제를 고쳤습니다. 이제 `unassignFamily`로 미배치 상태가 됩니다.
- **영주**: 영향력과 왕의 총애를 바꿔도 HUD가 갱신되지 않았습니다. 이제 `updatePlayerStats`를 부릅니다. 기능이 꺼져 있을 때 "현재" 값이 멈춰 있던 문제도 고쳤습니다.
- **패널**: 한글 IME로 입력한 전각 숫자를 숫자 칸이 버리던 문제를 고쳤습니다.
- **재구성**: 제거 대기 상태가 남아 다음 재구성이 멈추던 문제와, 용병 종류로 저장된 생성 분대를 인식하지 못하던 문제를 고쳤습니다.
